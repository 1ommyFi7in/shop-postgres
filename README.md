## Как выглядит результат

В seed пользователь `7` существует, товар `11` — «Кружка» с SKU `SKU-11`, ценой `49.90` и остатком `3`.

| Вход | Ожидаемый результат |
| --- | --- |
| Пользователь `7`, товар `11` × 2 | Новый заказ с позицией `2 × 49.90`, итог `99.80`, остаток `1` |
| Затем тот же товар × 2 | Ошибка нехватки, нового заказа нет, остаток `1` |
| Затем изменить цену товара на `59.90` | Выручка по созданному заказу остаётся `99.80` |

## Проверка перед сдачей

- [ ] Прогнать пример и гонку в двух SQL-сессиях. Сохранить команды, результаты и проверки PK/FK/UNIQUE/CHECK.
- [ ] Проверить выручку с двумя позициями и пользователя без заказов. Для углубления восстановить дамп в отдельную БД.
